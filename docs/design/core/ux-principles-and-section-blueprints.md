# UX principles and section blueprints

## Principles
One focal point per viewport. Gestalt proximity, similarity and alignment. Nielsen heuristics most used on marketing sites: system status, real-world language, consistency, error prevention and recovery, recognition over recall, minimalist design. Fitts: large primary CTA on the reading path, sticky mobile CTA on long pages. Hick: one primary CTA per section, 4–6 top nav items. Jakob: logo top-left links home, legal in footer. Serial position: strongest proof after the hero, strongest CTA at the end. Nothing essential is hover-only.

## Home skeleton
Nav → Hero → Proof strip → How it works → Value blocks → Detail (product or use cases) → Trust → FAQ → Final CTA → Footer.

## Hero blueprints
H1 Split (text 6 cols, media 6 cols). H2 Editorial (full-width display type, media below; Nothin'). H3 Media-first (full-bleed photo or video, text over a scrim; QuickBite, Vectura). H4 Product (short centered headline over a large product screenshot). H5 Immersive (scroll drives a scene; level 4 only; Igloo).

## Feature blueprints
F1 Numbered steps with image (Ontiver, QuickBite). F2 Bento of mixed tile sizes. F3 Alternating rows (max 3). F4 Sticky heading with scrolling list. F5 Selector controlling a preview (QuickBite app showcase). F6 Comparison table.

## Proof blueprints
Counted logo strip; 3–4 real metrics with units and dates; testimonial masonry with names and roles; regulator row with registration numbers linking to verification; named contact cards (Vectura).

## Responsive
Stack in reading order (media first only when it is the product). Hero headline ≥ 2.25rem at 360px. Horizontal scroll only for carousels with visible overflow and buttons. Mobile nav in a Sheet, primary CTA visible in the header. Test 320, 375, 414, 768, 1024, 1280, 1440, 1920.
