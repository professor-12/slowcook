# Design standard (docs/design)

These files are the reusable frontend design standard (core pack plus niche packs) supplied by the project owner on 2026-11-12. SlowCook uses the **fintech** pack: it moves money, so fintech trust and copy rules apply.

| File | Status for SlowCook |
|---|---|
| `core/PRD.md` | Filled in for SlowCook |
| `reference-sheet.md` | Filled in for SlowCook |
| `qa-report.md` | QA checklist results with evidence |
| `core/*.md` (other files) | The standard, unchanged except: citation markers removed, and the Tailwind v4 code example in `design-system.md` §8 replaced by a pointer (SlowCook's tokens are in `apps/web/app/globals.css`) |
| `niches/fintech/*` | The niche pack used |
| `niches/_new-niche-method.md` | Kept for future niches |

Only the core files and the fintech pack are copied here. The gaming, professional and playful packs are not used by this project.

The standard's research sources (Anthropic's "Improving frontend design through Skills", WCAG 2.2, Core Web Vitals, Material Design 3 motion tokens, Radix Colors, shadcn/ui on Tailwind v4, and the Ontiver and QuickBite repositories) are listed in the owner's original document.
