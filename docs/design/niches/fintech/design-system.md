# Fintech overrides (proposed)
Color: --background #FFFFFF, --surface-2 #F5F7F6, --border #E3E8E6, --foreground #0B1A14, --muted-foreground #52605A, --primary deep green #0E5A43 or navy #0B2A4A, --accent #19C37D (highlights and positive data), --positive #0F7A4E, --negative #C23B2B. No red brand color, no neon gradients; pair data colors with +/− signs and icons.
Type: General Sans or Instrument Sans display; Satoshi or IBM Plex Sans body; tabular-nums everywhere; Plex Mono or Geist Mono for account numbers. Neutral type reads as trustworthy.
Shape: soft radius 6–16px, borders over shadows, 44px table rows.
Imagery: real product UI with plausible data and people in real settings (Ontiver). No coins, rockets or 3D money.
Components: regulator line, verifiable badge row, fee table, calculator showing assumptions, step indicator, OTP input, status timeline.
Libraries: shadcn/ui + Magic UI (Number Ticker on real dated numbers, Marquee for logos). No Aceternity backgrounds.
References: Ontiver, Trustly travel, Payaza, Wise and Stripe pricing pages.
